# kittycatgit Extensions (0.8)

Paperback 0.8 extensions.

## Sources

- [CoffeeManga](https://coffeemanga.net)
- [Kagane](https://kagane.to)
- [Rawkuma](https://rawkuma.net)

## Install

Add this URL in Paperback under Settings → Extensions:

```
https://kittycatgit.github.io/kitty-extensions-0.8
```

Or open [this link](paperback://addRepo?url=https%3A%2F%2Fkittycatgit.github.io%2Fkitty-extensions-0.8) on your device.
